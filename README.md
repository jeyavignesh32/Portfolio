# Jeyavignesh J — Professional Portfolio

A responsive React + Vite developer portfolio with a dark charcoal theme, mint accents, subtle motion, project showcase, skills, internship experience, education, achievements and contact form.

## Run locally

1. Install Node.js (LTS).
2. Open this folder in VS Code / terminal.
3. Run:

   ```bash
   npm install
   npm run dev
   ```

4. Open the local URL printed by Vite (usually http://localhost:5173).

## Contact form

The contact form is configured with FormSubmit to deliver messages to `jeyavignesh0732@gmail.com`. On the first live submission, FormSubmit sends an activation email to that inbox. Open it and confirm activation before expecting future messages to be delivered. The form requires an internet connection and the deployed site must be served over the web.
